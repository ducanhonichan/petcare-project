# PetCare - Project Scope

## 1. Project Overview

PetCare is a web application designed to help pet owners manage their pets' health information, including pet profiles, weight tracking, vaccination records, and vaccination reminders.

## 2. Technology Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MySQL
- Authentication: JWT
- Charts: Chart.js / Recharts
- Version Control: Git & GitHub

## 3. Core Features (MUST HAVE)

1. User Registration and Login
2. Pet Profile Management (CRUD)
3. Pet Weight Tracking
4. Weight History Chart
5. Vaccination Records
6. Vaccination Reminders
7. Dashboard

## 4. Optional Features (NICE TO HAVE)

1. Medical Records
2. Admin User Management
3. Pet Image Upload
4. Automated Email Reminders

## 5. Team Responsibilities

### Person 1
- Pet Profile Management
- Weight Tracking and Charts
- Dashboard
- Database Design
- Frontend Development

### Person 2
- User Authentication (JWT)
- Vaccination Management
- Vaccination Reminders
- Admin Features

Both members collaborate on integration, testing, and documentation.

## 6. Project Timeline

- Week 1: Planning and Project Setup
- Week 2: Database and Authentication
- Week 3: Pet Management
- Week 4: Weight Tracking and Vaccination
- Week 5: Dashboard and Core Demo
- Week 6: Optional Features
- Week 7: Testing and Documentation

## 7. Project Goals

- Build a functional full-stack web application.
- Implement RESTful APIs.
- Store and manage pet health data using MySQL.
- Provide a responsive and user-friendly interface.
- Maintain a clear GitHub commit history throughout development.
